# Skill Card: Chinese Code Comments

## Capability

Adds concise Chinese interface comments.

## Use Cases

- Documenting an important interface in a code change.

## Inputs and Outputs

- Input: the interface definition to document.
- Output: a concise Chinese comment stating its purpose and constraints.

## Dependencies

- None.

## Limitations

- Reserved for important interfaces, not every line of code.

## Maintainer

Owner: APM maintainers
Support: Report issues through the APM project issue tracker.
