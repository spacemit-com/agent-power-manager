# Skill Card: Test Case Namer

## Capability

Names tests by observable behavior.

## Use Cases

- Naming an automated test case.

## Inputs and Outputs

- Input: the behavior a test verifies.
- Output: a test name derived from that behavior.

## Dependencies

- None.

## Limitations

- Names only; it does not design or implement the test.

## Maintainer

Owner: APM maintainers
Support: Report issues through the APM project issue tracker.
