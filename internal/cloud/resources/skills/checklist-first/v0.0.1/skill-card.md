# Skill Card: Checklist First

## Capability

Creates an outcome-focused checklist before execution.

## Use Cases

- Turning a request into an execution checklist before starting work.

## Inputs and Outputs

- Input: the user's request.
- Output: a checklist of the required outcomes.

## Dependencies

- None.

## Limitations

- Covers outcomes only; it does not plan implementation details.

Owner: APM maintainers
