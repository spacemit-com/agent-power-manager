# Skill Card: Commit Message Helper

## Capability

Formats a short imperative conventional commit subject.

## Use Cases

- Writing a conventional commit message.

## Inputs and Outputs

- Input: the change to describe.
- Output: an imperative `type(scope): summary` subject under 72 characters.

## Dependencies

- None.

## Limitations

- Subject line only; it does not write the commit body.

## Maintainer

Owner: APM maintainers
Support: Report issues through the APM project issue tracker.
