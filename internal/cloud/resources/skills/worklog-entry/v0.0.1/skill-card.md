# Skill Card: Worklog Entry

## Capability

Records work, result, and follow-up concisely.

## Use Cases

- Recording a concise worklog entry.

## Inputs and Outputs

- Input: completed work and its outcome.
- Output: three short lines covering work, result and follow-up.

## Dependencies

- None.

## Limitations

- Limited to three lines; not a full report.

Owner: APM maintainers
Support: Report issues through the APM project issue tracker.
