# Skill Card: Error Context

## Capability

Adds operation and target context to errors.

## Use Cases

- Reporting an operation failure.

## Inputs and Outputs

- Input: a failed operation and its target.
- Output: an error message that names both.

## Dependencies

- None.

## Limitations

- Adds context only; it does not classify or retry the failure.

Owner: APM maintainers
