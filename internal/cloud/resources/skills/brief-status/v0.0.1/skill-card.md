# Skill Card: Brief Status

## Capability

Produces a concise status update with no more than three next actions.

## Use Cases

- Writing a concise progress status update.

## Inputs and Outputs

- Input: the current work state.
- Output: one sentence of result plus at most three next actions.

## Dependencies

- None.

## Limitations

- Next actions are capped at three; not a long-form report.

## Maintainer

Owner: APM maintainers
Support: Report issues through the APM project issue tracker.
