# Skill Card: Plain Language

## Capability

Keeps user-facing technical text understandable.

## Use Cases

- Writing user-facing technical text.

## Inputs and Outputs

- Input: technical text intended for end users.
- Output: text that prefers familiar words and defines unavoidable terms once.

## Dependencies

- None.

## Limitations

- Aimed at user-facing text, not internal documentation.

## Maintainer

Owner: APM maintainers
Support: Report issues through the APM project issue tracker.
